# RISCV-Multicycle-Control-Unit-Logisim
Implementation of a Multicycle Control Unit for a RISC-V processor using Logisim. Generates essential control signals based on instruction opcodes and states.


## Features

* Control unit design using digital logic.
* Finite State Machine (FSM) based control.
* Next-state logic and control signal generation.
* Designed for learning computer architecture and processor control.

## Tools Used

* Logisim
* Digital Logic Design
* RISC-V Computer Architecture

## Project Files

The repository contains the Logisim circuit file and related project resources.

## Learning Objectives

* Understand multicycle processor control.
* Learn FSM-based control unit design.
* Understand how control signals are generated for processor operations.
